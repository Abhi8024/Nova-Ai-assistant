 NOVA – Personal Voice Assistant
NOVA is a Python-based personal voice assistant that listens to voice commands and performs everyday tasks.

Features:
Voice recognition
Text-to-speech responses
Tells the current time
Tells today's date
Opens Google, Gmail, Facebook and YouTube
Plays music using voice commands

Technologies Used:
Python
SpeechRecognition
PyAudioWPatch
pyttsx3

Installation:

Clone this repository:

bash
git clone https://github.com/Abhi8024/Nova-Ai-assistant.git

Install dependencies:
bash-
pip install -r requirements.txt

Run NOVA:
bash-
python main.py
