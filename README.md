# NOVA - Personal Voice Assistant

A Python voice assistant that listens to commands and performs everyday tasks.

## Features
- Voice recognition
- Text-to-speech responses
- Tells the current time and date
- Opens Google, Gmail, Facebook and YouTube
- Plays music by voice command

## Installation
```bash
git clone https://github.com/Abhi8024/Nova-Ai-assistant.git
cd Nova-Ai-assistant
pip install -r requirements.txt
python main.py
```
